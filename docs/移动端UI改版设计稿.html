掌上村务 安卓端视觉改版

只改「长相」，不改行为 —— 功能、接口、路由、表单校验、权限、文案全部保持 v1.0.6 现状；色值受测试保护不动，字号按舒适度重排，改版通过形状 / 阴影 / 布局 / 字号层级表达现代感。已随 v2.0.0 发布。
设计语言：六项变化
每一个变化都对应旧版一个具体问题，不是换皮。
1

大圆角卡片

卡片圆角从「各自为政」的 9–12dp 统一到 20dp。旧版一屏六张卡片三种圆角，会读成三个层级，其实它们平级。统一之后卡片像「一组」，而不是一堆。

旧 8
旧 12
新 20
2

柔和阴影浮起

卡片增加 4dp 柔和投影，白卡「浮」在 #F4F6FA 灰底上，不再靠 1px 描边硬切。原描边保留兜底——个别低端机 Layer 合成会裁掉阴影。

box-shadow · 4dp
3

浅色简洁头卡

首页头部不加底色，跟随页面浅灰底：状态栏深色字、问候行深色主文字、日期降为三级灰。品牌蓝不做大面积色块，只收在头像里做小面积锚点——大面积品牌色显沉，报数界面更需要干净的浅色阅读区。旧版贴顶的口径说明升级为内容区第一张独立口径卡（淡蓝底深蓝字），报数的人最需要的一句话有专属卡片。

4

胶囊选中导航

底部导航选中态：图标加浅蓝胶囊底，不再只换图标颜色。网格员在户外强光下，颜色变化难分辨，「形状变化」比「色相变化」可靠得多。

5

2×2 数据格

人口概况四格：主指标「总人口」用品牌浅底压住，次要指标安静灰底。数字放大到 23sp 加粗——这屏就是拿去会上念数的，数字必须是视觉第一落点。

6

宽松留白

卡片内边距 16dp、卡片间距 12dp、列表项头像 44dp。旧版 padding 10–14dp 偏挤，老花镜用户读起来费劲。留白是最便宜的「高级感」。

card padding 16dp · gap 12dp

落地说明
评审通过后按此实施；如有意见（圆角大小、阴影轻重、Hero 取舍）先改设计稿，再动代码。

改什么

  • 形状系统：新增 AppShapes 形状令牌（card 20dp / shadow 4dp），圆角从各组件内联值收敛到一处，改版只改一个文件
  • 卡片组件：StatCard / SectionCard 已切换到大圆角 + 柔和阴影 + 16dp 留白
  • 首页：浅色简洁头卡——无底色、无渐变，状态栏深色字，问候行深色主文字，品牌蓝只做头像锚点；口径说明为内容区第一张独立口径卡；2×2 数据格仅主指标「总人口」用品牌浅底，其余安静灰
  • 底部导航：选中态加浅蓝胶囊底
  • 人员列表：PersonRow 卡片化（头像圆牌 + 证件号 + 标签胶囊）。⚠️ 设计稿示意画的是脱敏证件号，实施按代码既有决策保持**完整号码**——这一屏的使用场景是拿手机对着人逐位核身份，脱敏后反而没法核对（代码注释有完整理据）
  • 表单 / 拍照留痕：分区卡片 + 大圆角控件 + 芯片多选，见预览新增两屏
  • 详情页 / 待核查 / 我的：按上图同规范对齐
  • 实施偏差记录（v2.0.0）：① 人员行标签实施为文字下方成排胶囊而非设计稿右侧竖列——真实数据一人常挂 4~5 个标签，竖列会把卡片撑高一倍；② 待核查卡保留第三个「确认入库」文字按钮——它对应后端确认建人的重动作，不能没有入口，设计稿每张卡只画了两个按钮；③ 详情页底部三按钮操作栏撤掉后，电话改为信息行内点按拨号、拍照入口收进「现场照片」卡——功能不因版式调整而丢失

不碰什么（红线）

  • 色值不动：17 项颜色令牌被 AppTokensTest 逐条钉在《移动端设计说明》上，改版只用形状 / 阴影 / 布局说话
  • 字号校订：17sp / 22sp 不再锁死，改版按「阅读舒适度」重排字号层级——层级拉开、正文守住可读下限、辅助信息允许更小；以真机观感为准，不为「保持现状」而保持现状。
  • 功能不动：接口、路由、表单校验、权限、离线缓存、文案全部保持 v1.0.6 行为
  • 深色模式不动：派生色表已完整，改版只重画浅色档的层次
